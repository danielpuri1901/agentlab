AgentLab Project Map

Experimentation platform for autonomous agents + AWS learning project. Budget $1,000 all-in. Source of truth: docs/phase0-synthesis.md and docs/plans/2026-08-16-v01-local-verdict.md.

Seven TDD tasks from the plan. Only adopted dependency: Inspect (UK AISI). Everything else is thin, owned code.

3. The verdict logic: AgentLab's actual core

The one thing no shipping product does: a gate that refuses to call noise a result.

flowchart TB
  T["Paired trials: baseline + candidate
on identical tasks and seeds"] --> CI["95% CI on mean per-task delta"]
  CI --> Q1{"CI lower bound > 0?"}
  Q1 -- yes --> Q2{"Protected metrics within
allowance? (e.g. cost)"}
  Q2 -- yes --> PROMOTE["PROMOTE"]
  Q2 -- no --> HOLD["HOLD
better, but regressed a guardrail"]
  Q1 -- no --> Q3{"CI upper bound < 0?"}
  Q3 -- yes --> REJECT["REJECT"]
  Q3 -- no --> INC["INCONCLUSIVE
the honest third answer"]

4. v0.2: the AWS fabric (planned, numbers pending the pilot)

Same experiment spec, second execution backend. This is the deliberately hand-built distributed-systems curriculum: queue, orchestration, isolation, state.

flowchart LR
  CLI2["agentlab CLI"] --> SQS["SQS work queue
one message per trial"]
  SQS --> SFN["Step Functions Standard
ECS .sync per run
retries, timeouts"]
  SFN --> FG["Fargate task (ARM, eu-west-1)
public subnet, no NAT
Bedrock-scoped task role only"]
  FG --> BR2["Bedrock global endpoint"]
  FG --> S3["S3: EvalLogs + artifacts
gateway endpoint, free"]
  FG --> DDB["DynamoDB: run state machine
idempotent transitions"]
  FG --> CW["CloudWatch: logs + alarms
retention set, no per-experiment metrics"]
  S3 --> STATS2["same stats.py"]
  STATS2 --> V2{"same verdict
must reproduce v0.1"}

6. The stack, first build

  • Language Python 3.12
  • Env/packaging uv
  • Eval framework inspect_ai + inspect_evals
  • Schemas pydantic v2
  • Stats scipy (paired CI) + statsmodels (power)
  • CLI / report typer + jinja2
  • Corpus / analysis faker + pandas
  • Prices litellm model price map
  • Quality pytest + ruff
  • Models Bedrock: Nova Lite default; Haiku/Sonnet confirmation tiers
  • v0.2 infra SQS, Step Functions, Fargate (ARM), DynamoDB, S3, CloudWatch, Terraform
