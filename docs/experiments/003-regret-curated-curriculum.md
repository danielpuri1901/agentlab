# Experiment 003: regret-curated curriculum vs fixed teacher curriculum

Status: PRE-REGISTERED 2026-08-21, from the approved proposal "Self-Play Synthetic Environments for Agent Reasoning" (Daniel tap-approved 2026-08-20).
Full derivation and paper grounding: docs/deep-dives/2026-08-21-spade-self-play.md (arXiv:2608.19197).
Pre-registered before any trial runs.

## Hypothesis

Under a fixed curriculum size, in-context example tasks that the model under test generates and regret-filters itself improve its held-out multi-turn tool-use success rate more than an unfiltered curriculum written once by a fixed strong model.
This is the inference-time analog of SPADE's core curation claim.
No weights are updated in either arm; the paper's actual training loop is explicitly out of reach on our Bedrock-hosted stack.

## Task family (new)

Multi-turn tool-use scenarios with a simulated backend (for example a ticket system with search_ticket, update_ticket, issue_refund).
Success is checked in code by comparing final backend state to a target state; no LLM judge.
The scenario Designer is constrained to a fixed JSON schema interpreted by our own Python checker, never arbitrary generated code.
That constraint is a named threat to validity (trades away the paper's generality for safety on our stack).

## Arms (paired on identical held-out task seeds)

- Baseline `teacher_curriculum`: curriculum generated once by a fixed strong model, no filtering.
- Candidate `regret_curriculum`: same curriculum size, generated by the model under test and filtered by hint-based regret scoring at inference time.

## Design

- Standard gate (PROMOTE / REJECT / INCONCLUSIVE), paired deltas on held-out success rate, MDE 0.10.
- Screening on Nova Lite with validity gates (both arms off floor and ceiling); sized run from measured variance; Haiku 4.5 confirmation if the CI excludes zero.
- Budget cap: $40.00 total (the lab's most expensive run to date; abort and surface if exceeded).

## Implementation deltas

New Inspect task family (tool-use scenarios + JSON scenario schema + state-comparison scorer), a regret-scoring step, curriculum assembly, and a `--task-family` wiring extension.
Queue position: built together with experiment 002 (shares the seeded-generator machinery).
